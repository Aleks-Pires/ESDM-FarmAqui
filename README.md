# FarmaAqui

Projeto acadêmico da disciplina **Engenharia de Software para Dispositivos Móveis**.

O FarmaAqui tem como proposta facilitar a localização de medicamentos e reduzir deslocamentos desnecessários de pacientes e cuidadores, especialmente em cidades pequenas.

## Estado inicial

Este repositório contém a estrutura inicial do projeto. A implementação da autenticação será desenvolvida em uma branch de funcionalidade e submetida por Pull Request.

## Plataforma

- Android
- Flutter / Dart
